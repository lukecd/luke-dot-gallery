# Luke’s Apps assets

- `envelope.png`: generated specifically for this admin from Luke’s approved reference. Raster illustration, 780 × 520. Prompt: flat cut-paper envelope, tilted counterclockwise, lilac body, ivory folded flap, coral seal and three coral rays; no text or plants. The source image has an opaque turquoise background. `envelope-mask.svg` clips that background at display time; it contains only a silhouette mask, not replacement illustration artwork.
- Fonts: Paytone One (display) and DM Sans (400–700), self-hosted from Google Fonts. Their SIL Open Font Licenses are included beside the font files. Official upstream: https://github.com/google/fonts/tree/main/ofl/paytoneone and https://github.com/google/fonts/tree/main/ofl/dmsans.
- Interface icons use the existing `react-icons/pi` dependency’s Phosphor Duotone family. No paid icon assets were added.

The palette and font variables are scoped to `admin-theme.module.css`. The public Sow marketing site retains its existing design.
