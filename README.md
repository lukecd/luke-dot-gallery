# Luke.gallery

Luke Cassady-Dorion's personal portfolio, built with Next.js, React Three Fiber,
TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

- `npm run dev`: start the Next.js development server
- `npm run build`: create the production Next.js build
- `npm run start`: serve the production build
- `npm test`: build and verify the rendered portfolio
- `npm run lint`: lint the project

The repository uses the standard Next.js build pipeline and deploys directly to
Vercel from GitHub.
